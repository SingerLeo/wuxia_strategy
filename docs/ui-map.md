## 2. P0 页面

### 门派（总览）🔧
- **看什么**：门派概况、日期、银两、人数、平均体力/忠诚；**本旬提醒**（有人闲着、有人太累）
- **能做什么**：（后续）查看收支明细
- **依赖**：`Game.sect`、`Game.reminders()`
- **以后加**：收支预估、最近事件摘要、荣耀/威望进度

### 弟子（名册）🔧
- **看什么**：名册表格（姓名、年龄、专长、体力、本旬安排）；右侧详情（武学/基本功/心智三列 + 六维雷达、状态、性格）
- **能做什么**：**批量安排**（全部休息、按专长指派日程；单人指派在「训练」页）；**点表头排序**
- **依赖**：`Game.set_plan`、`rest_all()`、`train_all_by_specialty()`
- **以后加**：筛选、阶位晋升、师徒关系、已装配武学、履历页签、逐出门派

### 训练 ✅
- **看什么**：日程列表（各有几人）；所选日程的各科目份数（合计 20）、强度、本旬实际分到各项的比例；弟子-日程指派表（姓名、专长、体力、日程）
- **能做什么**：新建/删除/改名日程，调各科目份数与强度；表里点「日程」列下拉给单人指派；批量：按专长指派、全部用所选日程、全部休息
- **依赖**：`Training`、`Schedule`、`Game.assign/add_schedule/remove_schedule/set_schedule_slots/set_schedule_intensity`
- **以后加**：教习（长老）一栏，按科目指定指导者

### 招收 ✅
- **看什么**：本季候选人列表（姓名、年龄、专长、性格、要价）；右侧详情（资质 1~20 分、入门所学）
- **能做什么**：招收（花银两，不足时按钮禁用）/ 婉拒；每季自动刷新一批
- **依赖**：`Recruitment.generate/asking_price`、`Game.recruit()/decline()`，质量随威望提升
- **验收**：招收后进入名册，银两减少，威望影响候选质量 ✅（见 test_recruitment.gd）

### 建筑 ✅（图形化山门地图）
- **看什么**：左侧是 12×8 的**山门地图**（山石、池塘不可建），建筑按占地画成色块并标出等级；带 ▲/▼ 的建筑表示受位置加成或影响。右侧是建筑清单，以及选中建筑的效果、位置加成条件、对邻居的影响。
- **能做什么**：
  - **建造**：清单里点"建造" → 地图上出现预览，**建筑中心跟着鼠标**（绿色可放、红色不可放，下方提示原因与位置加成倍率；**会产生加成或影响的邻居会被框出来**，绿框 ▲ 有加成、红框 ▼ 受影响）→ 左键放下；**滚轮、R 键或"旋转"按钮**旋转 90°；右键 / Esc 取消。
  - **拖拽移动**：直接按住地图上的建筑拖到新位置再松开（按住的那一格一直跟着鼠标）；放不下或松在地图外会自动回到原处，原位置留一圈虚框。
  - **选中**：点地图上的建筑或清单里的名字，查看详情；鼠标悬停在建筑上会高亮。
  - **升级**（花银两）、**移动**（免费，重新选址）、**拆除**（点两次确认，退还已投入的 50%）。
- **位置规则**（`Catalog.SYNERGIES`，占位数值）：药庐紧挨练武场 ×1.5；伙房紧挨药庐 ×1.25；藏经阁离练武场 2 格以内 ×0.7。
- **依赖**：`SectMap`（地形、占地、邻接）、`Economy`、`Game.build_at / move_building / demolish_building / upgrade_building`。
- **验收**：位置影响实际效果 ✅（见 test_sect_map.gd）；摆放、取消、移动、拆除交互 ✅（见 test_building_page.gd）。
- **以后加**：买地扩大山门；更多建筑与尺寸；建筑之间的道路/风水；拖拽摆放。

### 产业 ✅
- **看什么**：田产、商铺的数量/上限、单价、每旬收入、回本旬数
- **能做什么**：购置（花银两，已达上限或银两不足时禁用）
- **依赖**：`Catalog.ESTATES`、`Game.buy_estate()`
- **验收**：购置后每旬收入增加 ✅

### 武学 ⬜
- **看什么**：武学树（节点、前置、互斥路线）、研修队列与进度
- **能做什么**：选择研修目标、投入研修点
- **依赖**：（待做）武学数据与研修机制；弟子详情页补"装配"
- **验收**：研修完成后可装配，影响弟子能力

### 系统（存档）✅
- 自动存档（每旬结束，独立槽位）+ 3 个手动槽位（`user://save_slot_N.json`），JSON 带版本号与保存时间；Esc 菜单进「存档 / 读档」面板，每个槽位可存入/读取。
