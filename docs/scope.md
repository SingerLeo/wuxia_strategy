# 游戏范围（Scope）v0.1

> 本文件回答"游戏到底包含什么、先做什么、做到什么程度"。设计细节见 `design.md`，界面见后续的 `ui-map.md`。

## 1. 已确定的决策

| 项目 | 决定 |
|---|---|
| 核心理念 | **养成经营是主体，江湖与战斗是养成的"正反馈"**。参照：三国志（平时经营，打仗是反馈）、足球经理（平时安排，比赛是反馈） |
| 开发顺序 | 先做养成经营，再做江湖与战斗作为反馈 |
| 主线剧情 | **无主线**，纯沙盒 |
| 支线任务 | 部分门派/势力带有目标型支线，完成后获得奖励。例：五岳剑派并派，完成的掌门获得"荣耀值" |
| 失败条件 | **门派灭亡**（具体判定见 §4，待确认） |
| 势力规模 | 长期目标 **10+ 甚至 20+** 个势力；MVP 先做少量，但数据结构必须按"可大量扩展"设计 |
| 美术风格 | **暂不定**，界面保持主题化与组件化，以后可换 |
| 引擎/技术 | Godot 4.7 + GDScript，逻辑与界面分离，可无界面测试 |

## 2. 核心循环（"经营 → 反馈 → 回报"）

```
安排（修炼/任务/研修/招收）──▶ 结算（成长、收入、事件）
        ▲                              │
        │                              ▼
   回报反哺养成  ◀──  反馈（江湖事件 / 火并 / 支线任务）
 （声望、荣耀、俘虏、武学残篇、资源）
```

- **平时**：玩家做的是安排与取舍，这是游戏的大部分时间。
- **反馈**：火并、江湖事件、支线任务检验并奖励前期的经营，它们是节点，不是日常。

## 3. 功能大类

优先级：**P0** 第一阶段必做；**P1** 第二阶段，作为反馈补上；**P2** 后续扩展。

| 类 | 内容 | 优先级 | MVP 范围 | 现状 |
|---|---|---|---|---|
| **A 门派经营** | 银两/声望/荣耀、俸禄与开支、设施、弟子编制 | P0 | 银两收支、声望、3~4 种设施 | 银两/声望/荣耀字段、总览页与本旬提醒已有；收支与设施未做 |
| **B 弟子培养** | 招收、资质、修炼、阶位、师徒、忠诚与去留 | P0 | 招收、阶位晋升、师徒关系、忠诚与叛门 | 成长结算（已按天才锚点校准）、名册/详情/批量安排、招收（每季刷新候选人、声望影响质量）、忠诚与叛门（过劳/低落驱动，归零出走）已完成；阶位、师徒未做 |
| **C 武学** | 武学树、研修、装配、克制 | P0（养成的一部分） | 1 条主路线、约 30 个武学 | 未开始 |
| **H 系统层** | 存档/读档、设置、新手引导、本地化 | P0（存档优先） | 单存档位 + 自动存档 | 存档已完成（JSON 带版本号、每旬自动存档、Esc 菜单）；设置/引导/本地化未做 |
| **D 江湖** | 地图节点、势力、关系值、外交、势力 AI | P1 | 约 5 个势力、12 个节点；数据驱动可扩到 20+ | 未开始 |
| **E 火并与战斗** | 战前布阵、自动战斗、战报、战利品 | P1 | 自动结算、简易布阵 | 未开始 |
| **F 招降与俘获** | 斩/放/收、武学残篇、仇家 | P1 | 基础版 | 未开始 |
| **G 事件与支线** | 事件库、季度大事件、支线任务、荣耀值 | P1~P2 | 约 50 个事件、2~3 条支线 | 未开始 |
| **I 扩展内容** | 势力扩到 20+、更多武学/门派特色/特色支线 | P2 | — | — |

### 依赖关系
- C（武学）依赖 B（弟子要能装配武学）。
- D（江湖）依赖 A、B：关系值与反馈要以门派实力为基础。
- E（战斗）依赖 B、C、D：谁出战、用什么武学、打谁。
- F（招降）依赖 E。
- G（事件/支线）依赖 D，奖励回灌 A（荣耀值、声望）。

## 4. 失败与胜利

**失败：门派灭亡。**

**已实现（占位版）**：弟子人数为 0 即灭亡。判定集中在 `Sect.is_destroyed()`，以后增删条件只改这一处；灭亡后显示"门派覆灭"遮罩，只能"重新开始"。开发时按 F9 可遣散全部弟子查看效果。

**以后可能加入的条件**：
- 掌门身亡且无继承人；
- 山门被占领且无力夺回（P1 做出江湖后才有意义）。

**没有硬性通关**。成就感来自：
- **荣耀值**：完成支线任务、统一某个联盟、击败强敌所得，作为长期成绩与排行依据。
- 可考虑"年度评价"或"结局评价"，把荣耀值转为评语（待定）。

## 5. 支线任务（目标型）

- 数据驱动：条件 + 奖励（荣耀值、声望、武学、人物）。
- 带有势力特色，如"五岳并派""重振旧派""夺回失传武学"。
- 完成后获得荣耀值与一次性奖励；不会强制推进，玩家可忽略。
- 属 G 类，P1~P2 实装；P0 阶段只需为荣耀值预留字段。

## 6. 第一阶段（P0）验收标准：一个"能玩的经营循环"

- 能开一局新游戏，有初始门派与 12 名弟子。
- 每旬能为每名弟子安排修炼或任务，结算后有明确成长反馈。
- 有银两收支与招收新弟子，资源紧张到需要取舍。
- 弟子有阶位、师徒、忠诚；会叛门；有弟子晋升的成就感。
- 武学能研修、装配并影响弟子能力。
- 能存档和读档。
- 所有逻辑有自动化测试。

## 7. 暂不决定（保持开放）

- 美术风格与资源方向（见 §1）。
- 具体数值平衡（成长速度、上限、收入），待经营循环成形后统一调。
- 势力的具体数量和名单、地图形状。
- 战斗的精细度（P1 再定）。
