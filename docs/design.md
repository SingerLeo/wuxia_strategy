# 武侠门派策略游戏 · 设计文档 v0.1

> 状态：草案。目标是先把核心循环和 MVP 范围钉死，再谈扩展。

## 1. 一句话定位

**养一批有个性的弟子，用武学路线与江湖势力周旋，把一个无名小派经营成一方霸主。**

- 类型：单人、回合制（以"旬"为单位）门派经营 + 轻战略
- 参考：FM（人才培养与长线成长）、三国志（俘获/招降/人际关系）、HOI4（科技树的路线取舍）
- 设计支柱：
  1. **人是核心**：每个弟子都是有性格、有成长曲线、有故事的个体，不是数值单位。
  2. **取舍胜过堆叠**：资源永远不够，武学路线互斥，每个决策都有代价。
  3. **战前决策重于战中操作**：火并靠布局、情报、搭配取胜，战斗本身自动结算。

## 2. 核心循环

**单回合（一旬，约 10 天）**

```
查看门派状态/事件 → 分配弟子任务 → 安排修炼与武学研究 → 处理外交/江湖事件 → 结算（成长、收入、战斗、随机事件）
```

**中循环（一季，3 旬）**：一次大型江湖事件（比武大会、门派拜帖、官府征召等），决定势力格局变化。

**长循环（一年，12 旬）**：弟子出师/晋升、年度考核、武学路线里程碑。

**玩家每回合的核心决策**
- 谁去修炼、谁去执行任务、谁休息养伤？（时间/体力是稀缺资源）
- 这笔银两用来买功法、扩建设施、还是收买情报？
- 要不要现在跟 A 派翻脸，还是先忍？

## 3. 系统设计

### 3.1 弟子系统（主轴，FM 式）

**属性**

| 类别 | 内容 |
|---|---|
| 基础资质 | 根骨、悟性、身法、胆识、心性（出生时确定，只能小幅变动） |
| 可成长属性 | 内力、外功、轻功、医术、谋略、口才（上限由资质决定） |
| 隐藏属性 | 潜力（上限）、成长曲线类型（早慧/晚成/稳健/起伏）、伤病倾向 |
| 状态 | 体力、士气、忠诚、伤势 |
| 性格词条 | 2~3 个（如：孤傲、重义、贪财、好胜、胆小），影响事件与忠诚 |

**成长**
- 每旬获得 `经验 = 基础值 × 修炼方式系数 × 悟性系数 × 师父加成 × 设施加成`
- 属性在经验达标时提升，提升幅度受成长曲线影响；年龄段影响（少年期成长快，壮年稳定，后期下滑，内力例外）。
- **师徒关系**：师父的武学与性格会传给弟子（继承部分武学、性格倾向），形成门内"传承谱系"。

**阶位**：外门 → 内门 → 执事 → 长老 → 掌门继承人。阶位决定可承担的任务与待遇。

**招收**：山门招生（每季一次，质量取决于门派声望与设施）、江湖收留（事件触发）、挖角/招降（见 3.5）。

**去留**：忠诚过低会叛门、被挖走、携武学出走（对应 FM 的球员流失）。

### 3.2 武学系统（HOI4 式科技树，但做减法）

- 武学分四大类：**内功心法 / 外家招式 / 轻功身法 / 辅学（医、毒、阵、铸）**。
- 门派选定 **1 条主路线**（如：刚猛外家 / 阴柔内功 / 剑法一脉 / 奇门杂学），路线之间部分互斥，决定后续可解锁的高阶武学。
- **研究机制**：消耗"研修点"（由有悟性的弟子/长老每旬产出）+ 银两；研究有时间成本（3~8 旬）。
- **双来源**：自创（走科技树）、夺取（击败/招降他派高手后获得残篇，需要补全）。
- **相克关系**：武学有克制（刚克柔、快克重、阵克散），但不是简单石头剪刀布，而是 ±15%~25% 的修正，由弟子熟练度浮动。
- **弟子装配**：每个弟子可携带 1 心法 + 2~3 招式 + 1 身法 + 辅学，搭配产生"套路协同"（如同系加成）。

> 取舍原则：科技树节点总数控制在 40~60 个，每个节点都要有明确、可感知的效果，避免"+5% 攻击"式节点。

### 3.3 门派经营

**资源**
- 银两（收入：地产、商铺、护镖、任务；支出：弟子俸禄、设施维护、研修）
- 声望（影响招生质量、外交筹码、任务池）
- 粮食/物资（可简化为银两的一部分，MVP 可省）
- 研修点、情报点

**设施（建在山门地图的有限格子上）**
练武场、藏经阁、药庐、铁匠铺、演武堂、客栈（收集情报/招揽）、粮仓。格子有限，逼迫取舍。

### 3.4 江湖与势力

- 地图：节点式（城镇、关隘、山门），非格子，MVP 约 12 个节点。
- 势力：官府、数个正派、邪派、商帮、散人。每个势力对玩家有 **关系值 (-100~100)**。
- 玩家的行动会引发关系变化（接任务、杀人、救人、结盟）。
- 势力有自己的 AI 目标（扩张、复仇、稳固），每季结算一次势力变动。

### 3.5 招降与俘获（三国志式）

- 战斗中击败敌方高手后，可选择 **斩 / 放 / 收**：
  - **收降**成功率 = f(对方忠诚、性格匹配、你的声望、劝降者口才、先前恩怨)
  - 高阶人物可能需要多次接触、完成其心愿任务。
- 被俘者带来 **武学残篇**、**人脉**（原门派关系变动）、**仇家**（风险）。
- 结义/联姻/师徒关系可提升忠诚与协同。

### 3.6 火并与战斗

**原则：战前决策 + 自动模拟，不做实时操作。**

- 流程：侦察（情报）→ 选人（出战 3~7 人）→ 布阵（前排/后排/奇袭/埋伏）→ 选战术（强攻/拖延/擒王/暗杀）→ 自动结算（带战报文字）。
- 单场按回合模拟（最多 10 回合），每回合出手顺序由身法决定，伤害 = 招式威力 × 内力/外功系数 × 克制修正 × 阵位修正 − 防御。
- 玩家可在战斗中 **有限介入**（每场 1~2 次"令旗"：撤退/换人/催动绝招），保留紧张感。
- 战斗结果影响：伤势、士气、声望、地盘、俘虏、武学残篇。

### 3.7 事件系统

- 事件驱动叙事：门内矛盾（师兄弟不合）、情感线、江湖传闻、天灾、官府压力。
- 事件由 **条件 + 权重 + 选项** 构成，数据驱动（JSON/表格），便于后续大量扩展。
- 弟子性格词条和关系网会实际触发定制事件，这是"人"的魅力来源。

## 4. 数值框架（初版，待调）

- 弟子属性范围 1~100；新弟子平均 25~40，潜力高者可达 90+。
- 一场势均力敌的战斗以"战力"比较：`战力 = Σ(个体战力) × 阵型系数 × 士气系数`，个体战力由属性与装配武学算出。
- 经济：中期每旬收入约为俸禄支出的 1.2~1.5 倍，保证"略有盈余但永远不够用"。
- 目标节奏：一局完整游戏 约 20 年（240 旬），实际游玩 8~12 小时。

## 5. MVP 范围（第一版必须做到）

**要做**
- 1 个可玩门派、约 20 名初始/可招弟子
- 弟子属性/成长/性格/忠诚 + 师徒传承
- 约 30 个武学，一条主路线科技树（分 3 个分支）
- 5 个对手势力 + 12 个地图节点
- 旬回合循环 + 季度事件
- 自动战斗 + 战前布阵 + 战报
- 招降系统（基础版）
- 约 50 个事件
- 文字/UI 为主，美术用占位图

**不做（留到后续）**
多门派可选、联机、复杂地图战略、婚姻/子嗣、物品装备深度系统、动画战斗、Mod 支持。

## 6. 技术建议

- **推荐**：Godot 4（GDScript/C#）或 Web（TypeScript + 简单 UI 框架）。两者都适合数据驱动的 UI 密集型游戏。
- 数据驱动：弟子模板、武学树、事件、势力全部放配置表（JSON/CSV），逻辑与内容分离。
- 存档：序列化整个游戏状态（JSON），预留版本号。
- 战斗模拟做成独立纯函数模块，方便单元测试与数值批量跑平衡。

## 7. 开发路线

| 阶段 | 内容 | 验证目标 |
|---|---|---|
| M0 | 数据模型 + 回合推进 + 弟子成长（无 UI/命令行也行） | 养成数值是否有趣 |
| M1 | 基础 UI + 任务派遣 + 经济 | 每回合决策是否有张力 |
| M2 | 武学树 + 装配 + 自动战斗 | 搭配是否有深度 |
| M3 | 势力/地图/外交 + 招降 | 外部压力与扩张感 |
| M4 | 事件系统 + 内容填充 + 平衡 | 一局能否完整跑完 |
| M5 | 打磨、美术音效、新手引导 | 可对外试玩 |

## 8. 主要风险与对策

| 风险 | 对策 |
|---|---|
| 范围蔓延 | MVP 清单硬性冻结，新想法进 backlog |
| 战斗黑洞 | 坚持自动模拟 + 战前决策，不做实时 |
| 武学树沦为数值堆叠 | 每个节点必须有机制性变化；路线互斥 |
| 内容量不足导致重复 | 事件数据驱动，优先做事件编辑流水线 |
| 数值失衡 | 模拟器批量跑 AI 对局，自动化平衡测试 |

## 9. 待决问题

1. 平台与引擎选择（Web / Godot / Unity）？
2. 美术风格：水墨？像素？纯文字 + 立绘？
3. 是否有明确剧情主线，还是纯沙盒？
4. 失败条件：掌门死亡？门派覆灭？还是无硬失败，只有结局评价？
5. 是否参考真实历史朝代，还是架空江湖？
