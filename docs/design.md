# 武侠门派策略游戏 · 设计文档 v0.1

> 状态：草案。目标是先把核心循环和 MVP 范围钉死，再谈扩展。

## 1. 一句话定位

**养一批有个性的弟子，用武学路线与江湖势力周旋，把一个无名小派经营成一方霸主。**

- 类型：单人、回合制（以"旬"为单位）门派经营 + 轻战略
- 参考：FM（人才培养与长线成长）、三国志（俘获/招降/人际关系）、HOI4（科技树的路线取舍）
- 设计支柱：
  1. **人是核心**：每个弟子都是有性格、有成长曲线、有故事的个体，不是数值单位。
  2. **取舍胜过堆叠**：资源永远不够，武学路线互斥，每个决策都有代价。
  3. **战前决策重于战中操作**：火并靠布局、情报、搭配取胜，战斗本身自动结算。

## 2. 核心循环

**单回合（一旬，约 30 天；一季 3 旬，一年 12 旬）**

```
查看门派状态/事件 → 分配弟子任务 → 安排修炼与武学研究 → 处理外交/江湖事件 → 结算（成长、收入、战斗、随机事件）
```

**中循环（一季，3 旬）**：一次大型江湖事件（比武大会、门派拜帖、官府征召等），决定势力格局变化。

**长循环（一年，12 旬）**：弟子出师/晋升、年度考核、武学路线里程碑。

**玩家每回合的核心决策**
- 谁去修炼、谁去执行任务、谁休息养伤？（时间/体力是稀缺资源）
- 这笔银两用来买功法、扩建设施、还是收买情报？
- 要不要现在跟 A 派翻脸，还是先忍？

## 3. 系统设计

### 3.1 弟子系统（主轴，FM 式）

**数值**（三类各 8 项，1~100，界面显示为 1~20 分；清单与对应关系见 `Balance`）

| 类别 | 内容 | 怎么涨 |
|---|---|---|
| **武学** | 剑法、刀法、枪棍、拳脚、指爪、暗器、医术、毒术 | 修炼、实战；速度与上限受悟性和对应项影响 |
| **基本功** | 内功、轻功、软功、硬功、根骨、耐力、身法、反应 | 修炼（受年龄曲线影响）；**根骨例外**：先天，只在少年期自然长 |
| **心智** | 悟性、定力、智谋、胆识、勤勉、魅力、统率、乐天 | **不能修炼**，只随年龄（每满一岁）与阅历增长 |
| **状态** | 生命、内力、体力（修炼疲劳，暂留）、心情、忠诚度、威望 | 随时间与事件变化 |
| 隐藏 | 潜力（可修炼项目的上限）、根骨与心智的先天上限、成长曲线（早慧/晚成/稳健/起伏） | — |

**对应项**（决定可修炼项目的成长速度与上限；对应项本身练高了，上限也跟着提高）：

| 项目 | 对应项 | | 项目 | 对应项 |
|---|---|---|---|---|
| 剑法 | 身法 | | 医术、毒术 | 智谋 |
| 刀法、枪棍、拳脚 | 硬功 | | 内功 | 定力 |
| 指爪 | 软功 | | 轻功、软功、硬功、耐力、身法、反应 | 根骨 |
| 暗器 | 反应 | | | |

**心智各项的用途**（✅ 已接入，其余待对应系统）：
- ✅ 悟性：所有修炼的速度；武学门槛。✅ 定力：内功的对应项。✅ 智谋：医术、毒术的对应项；任务、情报、外交。✅ 勤勉：修炼体力消耗（勤勉 50 → 20，100 → 15）。
- 胆识：以弱敌强时的士气、临阵脱逃。魅力：对外——外交、招收、江湖声望。统率：带队火并、长老/掌门职位。乐天：心情不易低落、恢复快；当师父或教习时带动徒弟与同门的心情与修炼。

**心智的增长**（`Growth.mature` / `Growth.gain_experience`）：
- 年龄：每满一岁，向先天上限补上 `差距 × 比例`（向上取整）。比例 <18 岁 20%，18~30 岁 12%，30~50 岁 6%，之后 2%。根骨 <18 岁 30%，成年后不再长。
- 阅历：任务、火并、江湖事件给某项心智 +N，并同时抬高先天上限（不会被以后的年龄增长"吃掉"）。入口已留，来源待江湖系统。
- 入门时根骨与心智约为先天上限的 60%。

**六维雷达**（`Dimensions.DEFS`）：武功（六种兵器/拳脚/暗器取最高）、内功（内功 0.6 + 定力 0.4）、轻灵（轻功 0.4 + 身法 0.4 + 反应 0.2）、体魄（根骨 0.3 + 硬功 0.3 + 软功 0.2 + 耐力 0.2）、才智（悟性 0.4 + 智谋 0.4 + 勤勉 0.2）、人望（统率 0.4 + 魅力 0.3 + 乐天 0.3）。医术、毒术、胆识不进雷达。

**训练**（`Training`、`Schedule`，界面在「训练」页）：
- **科目**：每个科目练一组固定的武学/基本功，经验按权重分到各项（心智不能修炼，不进科目）。

  | 科目 | 训练组合 |
  |---|---|
  | 剑术 | 剑法 60%、身法 25%、反应 15% |
  | 刀枪 | 刀法 35%、枪棍 35%、硬功 30% |
  | 拳脚 | 拳脚 50%、指爪 25%、硬功 25% |
  | 暗器 | 暗器 60%、反应 40% |
  | 内功打坐 | 内功 70%、软功 30% |
  | 轻功身法 | 轻功 50%、身法 30%、反应 20% |
  | 外家体能 | 硬功 40%、耐力 40%、软功 20% |
  | 医毒 | 医术 50%、毒术 50% |

- **日程**：每旬 **20 份**时间分给各科目，外加强度。弟子挂一个日程或休息。开局预设：剑客、刀枪、拳师、暗器、内家、医者、打基础；可改、可删、可新建。
  - 某项分到的时间比例 = Σ(科目份数/20 × 权重)。每项的经验 = 整旬经验 × 比例，仍各自吃悟性、对应项与年龄加成。所以专精练得快，全面发展慢。
  - 没分满 20 份：经验按比例少拿，体力也按比例少耗。
- **强度**：轻（经验 ×0.75、体力 ×0.6）/ 中（×1）/ 重（经验 ×1.25、体力 ×1.5）。
- **指导（教习）**：留接口 `Training.coach_mults`（科目 → 倍率），等长老/阶位系统做出来后由长老担任；目前恒为 1。
- 「按专长指派」：给每名弟子选「给其最高武学分配时间最多」的日程。

**武学门槛**：武学可以要求某些数值达到指定值（如独孤九剑需要悟性 90），不达标则学习进度打折扣；折扣曲线待定，目前为占位的线性折扣（`Growth.requirement_factor`）。

**修炼经验来源**：统一通过 `Growth.gain_xp`，修炼、实战、秘籍都走这个入口。
| 性格词条 | 2~3 个（如：孤傲、重义、贪财、好胜、胆小），影响事件与忠诚 |

**成长**
- 每旬获得 `经验 = 基础值 × 修炼方式系数 × 悟性系数 × 师父加成 × 设施加成`
- 属性在经验达标时提升，提升幅度受成长曲线影响；年龄段影响（少年期成长快，壮年稳定，后期下滑，内力例外）。
- **师徒关系**：师父的武学与性格会传给弟子（继承部分武学、性格倾向），形成门内"传承谱系"。

**阶位**：外门 → 内门 → 执事 → 长老 → 掌门继承人。阶位决定可承担的任务与待遇。

**招收**：山门招生（每季一次，质量取决于门派威望与设施）、江湖收留（事件触发）、挖角/招降（见 3.5）。

**去留**：忠诚过低会叛门、被挖走、携武学出走（对应 FM 的球员流失）。

### 3.2 武学系统（HOI4 式科技树，但做减法）

- 武学分四大类：**内功心法 / 外家招式 / 轻功身法 / 辅学（医、毒、阵、铸）**。
- 门派选定 **1 条主路线**（如：刚猛外家 / 阴柔内功 / 剑法一脉 / 奇门杂学），路线之间部分互斥，决定后续可解锁的高阶武学。
- **研究机制**：消耗"研修点"（由有悟性的弟子/长老每旬产出）+ 银两；研究有时间成本（3~8 旬）。
- **双来源**：自创（走科技树）、夺取（击败/招降他派高手后获得残篇，需要补全）。
- **相克关系**：武学有克制（刚克柔、快克重、阵克散），但不是简单石头剪刀布，而是 ±15%~25% 的修正，由弟子熟练度浮动。
- **弟子装配**：每个弟子可携带 1 心法 + 2~3 招式 + 1 身法 + 辅学，搭配产生"套路协同"（如同系加成）。

> 取舍原则：科技树节点总数控制在 40~60 个，每个节点都要有明确、可感知的效果，避免"+5% 攻击"式节点。

### 3.3 门派经营

**资源**
- 银两（收入：地产、商铺、护镖、任务；支出：弟子俸禄、设施维护、研修）
- 威望（影响招生质量、外交筹码、任务池）
- 粮食/物资（可简化为银两的一部分，MVP 可省）
- 研修点、情报点

**设施（建在山门地图的有限格子上）**
练武场、藏经阁、药庐、铁匠铺、演武堂、客栈（收集情报/招揽）、粮仓。格子有限，逼迫取舍。

### 3.4 江湖与势力

- 地图：节点式（城镇、关隘、山门），非格子，MVP 约 12 个节点。
- 势力：官府、数个正派、邪派、商帮、散人。每个势力对玩家有 **关系值 (-100~100)**。
- 玩家的行动会引发关系变化（接任务、杀人、救人、结盟）。
- 势力有自己的 AI 目标（扩张、复仇、稳固），每季结算一次势力变动。

### 3.5 招降与俘获（三国志式）

- 战斗中击败敌方高手后，可选择 **斩 / 放 / 收**：
  - **收降**成功率 = f(对方忠诚、性格匹配、你的威望、劝降者口才、先前恩怨)
  - 高阶人物可能需要多次接触、完成其心愿任务。
- 被俘者带来 **武学残篇**、**人脉**（原门派关系变动）、**仇家**（风险）。
- 结义/联姻/师徒关系可提升忠诚与协同。

### 3.6 火并与战斗

**原则：战前决策 + 自动模拟，不做实时操作。**

- 流程：侦察（情报）→ 选人（出战 3~7 人）→ 布阵（前排/后排/奇袭/埋伏）→ 选战术（强攻/拖延/擒王/暗杀）→ 自动结算（带战报文字）。
- 单场按回合模拟（最多 10 回合），每回合出手顺序由身法决定，伤害 = 招式威力 × 内力/外功系数 × 克制修正 × 阵位修正 − 防御。
- 玩家可在战斗中 **有限介入**（每场 1~2 次"令旗"：撤退/换人/催动绝招），保留紧张感。
- 战斗结果影响：伤势、士气、威望、地盘、俘虏、武学残篇。

### 3.7 事件系统

- 事件驱动叙事：门内矛盾（师兄弟不合）、情感线、江湖传闻、天灾、官府压力。
- 事件由 **条件 + 权重 + 选项** 构成，数据驱动（JSON/表格），便于后续大量扩展。
- 弟子性格词条和关系网会实际触发定制事件，这是"人"的魅力来源。

## 4. 数值框架（初版）

- 弟子属性范围 1~100；新弟子平均 25~40，潜力高者可达 90+。
- 一场势均力敌的战斗以"战力"比较：`战力 = Σ(个体战力) × 阵型系数 × 士气系数`，个体战力由属性与装配武学算出。
- 经济：中期每旬收入约为俸禄支出的 1.2~1.5 倍，保证"略有盈余但永远不够用"。
- 目标节奏：一局完整游戏 约 20 年（240 旬），实际游玩 8~12 小时。

### 4.1 弟子成长（已按锚点校准，常量见 `Balance`）

**每旬修炼经验**（`Growth.settle_xun`）：

```
经验 = BASE_XP(20) × 悟性系数 × 对应项系数 × 年龄倍率 × 体力效率 × 师父/设施/方式加成
悟性系数       = 0.5 + 悟性/100            （悟性 50 → 1.0，100 → 1.5）
对应项系数     = 0.7 + 0.6 × 对应项/100    （对应项 50 → 1.0，100 → 1.3）
年龄倍率       = 按成长曲线分年龄段         （早慧 <18 岁 1.5；晚成 25~45 岁 1.4；稳健 1.0；起伏 ±40% 随机）
体力效率       = 体力 ≥30 → 1.0，否则 0.5   （修炼 -20（勤勉 50 时）/ 休息 +35，稳态出勤约 64%）
```

**升级门槛**：`升到下一级所需经验 = 10 + 0.55 × 当前等级`，1→100 累计 3712.5。

**上限**（武学与基本功）：`上限 = 潜力 × (0.7 + 0.3 × 对应项/100)`，潜力 100 + 对应项 100 → 100。

**校准锚点**（改动修炼数值前必须先核对）：

- 潜力/悟性/对应项全 100、勤勉 50 的早慧型天才，12 岁起专攻一门，**10 年（120 旬）从 1 练到 100**（回归测试 `test_genius_maxes_a_skill_within_ten_years`，当前实测 111 旬 / 9.2 年）。勤勉更高的天才会更快。
- 群体表现（500 人 20 年模拟，种子 1）：中位数弟子约 8~10 年练到自身上限（平均上限 50）；第 20 年 ≥60 占 24%、≥80 占 1%。普通弟子的瓶颈是潜力上限而非经验，高手稀缺性由上限分布保证。

## 5. MVP 范围（第一版必须做到）

**要做**
- 1 个可玩门派、约 20 名初始/可招弟子
- 弟子属性/成长/性格/忠诚 + 师徒传承
- 约 30 个武学，一条主路线科技树（分 3 个分支）
- 5 个对手势力 + 12 个地图节点
- 旬回合循环 + 季度事件
- 自动战斗 + 战前布阵 + 战报
- 招降系统（基础版）
- 约 50 个事件
- 文字/UI 为主，美术用占位图

**不做（留到后续）**
多门派可选、联机、复杂地图战略、婚姻/子嗣、物品装备深度系统、动画战斗、Mod 支持。

## 6. 技术建议

- **推荐**：Godot 4（GDScript/C#）或 Web（TypeScript + 简单 UI 框架）。两者都适合数据驱动的 UI 密集型游戏。
- 数据驱动：弟子模板、武学树、事件、势力全部放配置表（JSON/CSV），逻辑与内容分离。
- 存档：序列化整个游戏状态（JSON），预留版本号。
- 战斗模拟做成独立纯函数模块，方便单元测试与数值批量跑平衡。

## 7. 开发路线

| 阶段 | 内容 | 验证目标 |
|---|---|---|
| M0 | 数据模型 + 回合推进 + 弟子成长（无 UI/命令行也行） | 养成数值是否有趣 |
| M1 | 基础 UI + 任务派遣 + 经济 | 每回合决策是否有张力 |
| M2 | 武学树 + 装配 + 自动战斗 | 搭配是否有深度 |
| M3 | 势力/地图/外交 + 招降 | 外部压力与扩张感 |
| M4 | 事件系统 + 内容填充 + 平衡 | 一局能否完整跑完 |
| M5 | 打磨、美术音效、新手引导 | 可对外试玩 |

## 8. 主要风险与对策

| 风险 | 对策 |
|---|---|
| 范围蔓延 | MVP 清单硬性冻结，新想法进 backlog |
| 战斗黑洞 | 坚持自动模拟 + 战前决策，不做实时 |
| 武学树沦为数值堆叠 | 每个节点必须有机制性变化；路线互斥 |
| 内容量不足导致重复 | 事件数据驱动，优先做事件编辑流水线 |
| 数值失衡 | 模拟器批量跑 AI 对局，自动化平衡测试 |
