# 门派资源 v0.2

> 三大资源：**银两、威望、底蕴**。本文记录用户给出的设计、已确认的决定、代码实现状态与待定项。
> 数值全是占位（见 `src/core/catalog.gd`、`balance.gd`），调平衡时再改。

## 1. 总览

| 资源 | 用在哪 | 从哪来 |
|---|---|---|
| **银两** | 购置产业、升级建筑；**持续支出**：养育弟子、建筑维护 | 产业收入；（以后）接任务；（供奉**暂缓**） |
| **威望** | 外交、招收弟子（当前实现为招收质量加成） | 弟子江湖经历（可涨可跌）、任务、踢馆、灭门 |
| **底蕴** | 解锁技能树（发展 / 策略 / 武功） | **获得的威望** + **弟子每旬的积累** |

另有 **历史最高威望**：只增不减，决定**可接任务等级**。

## 2. 银两
**收入**
- 产业收入：每旬，每处产业固定收入。
- 接任务：待任务系统。
- ~~成年弟子供奉~~：**暂缓**（成年线、额度未定）。

**支出**
- 购置产业、升级建筑（一次性）。
- 养育弟子：每人每旬 `Catalog.DISCIPLE_UPKEEP`（持续）。
- 建筑维护：每座建筑按等级每旬扣费（持续）。

**结算规则（每旬）**：`银两 += 产业收入 − 养育 − 维护`。银两不会为负；付不起的部分记为"缺口"，日志警告。**缺口的后果还没定**（候选：忠诚下降、弟子离开、建筑停摆），见 §6。

**开局**：1000 两，2 处田产（每旬 +18）。12 名弟子养育 24，所以开局每旬 −6，必须扩产业。

## 3. 产业与建筑
| 类别 | 项目 | 说明 |
|---|---|---|
| 产业 | 田产（上限 6，300 两，+9/旬）、商铺（上限 4，600 两，+20/旬） | 购置后每旬收入 |
| 建筑 | 练武场 | 每级修炼经验 +10% |
| 建筑 | 药庐 | 每级休息时多恢复 5 点体力 |
| 建筑 | 藏经阁 | 每级底蕴产出 +15% |
| 建筑 | 伙房 | 每级养育弟子的费用 -8% |

**建筑要在山门地图上摆放**（见 `docs/ui-map.md` 的建筑页）：占地不同（练武场 3×3、藏经阁 2×3、药庐与伙房 2×2），可旋转；位置会改变效果——药庐紧挨练武场 ×1.5、伙房紧挨药庐 ×1.25、藏经阁离练武场太近 ×0.7（占位数值）。拆除退还已投入花费的 50%。

建筑可升到 5 级，每级升级费和每旬维护费递增（`Catalog.BUILDINGS`）。

## 4. 威望与任务等级
- **用途**：外交；招收弟子。当前为**加成**——威望越高，候选人质量越好（`Recruitment.quality_bonus`）。（用户确认"现在对威望使用就好"，不改。）
- **变动**：弟子在江湖的经历、任务、帮派踢馆、灭门。这些大多依赖 P1 的江湖与战斗，P0 阶段威望先不会自己变化。
- **历史最高威望 → 任务等级**：取历史最高，所以威望下跌不会失去已解锁等级。门槛占位：0 / 50 / 150 / 400 / 1000 对应 1~5 级。
- 门派威望与**弟子个人威望**（弟子状态）是两个数，是否关联：待定。

## 5. 底蕴
- **来源（已确认）**：
  1. **获得的威望**：每获得 1 点威望，得 1 点底蕴（失去威望不扣）。
  2. **弟子每旬积累**：全体弟子本旬获得的技能经验 × 0.1。弟子修炼越多，门派底蕴越厚。
  - 藏经阁等级可提高底蕴产出。
- **用途**：解锁技能树。三大方向：
  - **发展**——经营（产业、建筑、收入效率）；
  - **策略**——外交、情报、任务；
  - **武功**——武学（即原来规划的"武学树"，C 类）。
- 技能树本身（节点、解锁花费）：**未做**。

## 6. 待定

3. **技能树**各方向的具体节点与解锁花费。
4. 威望的各种变动来源（等江湖、战斗、任务）。

## 7. 区分几个容易混的概念
| 概念 | 是什么 |
|---|---|
| 门派威望（资源） | 外交、招收的筹码，可涨可跌 |
| 历史最高威望 | 门派威望的最高纪录，决定任务等级 |
| 弟子个人威望 | 弟子的状态值（详情页状态区） |
| 荣耀值 | 长期成就的**成绩**（如支线"五岳并派"完成后获得），不可花费，**暂无功能，界面暂不显示**；字段保留在 `Sect.honor` |
| 弟子技能经验（xp） | 弟子个人的技能进度；其中一部分会转化为门派底蕴 |

- `Catalog`（目录与常量）、`Economy`（收支与建筑效果的纯计算）。
- `Game.buy_estate()`、`Game.upgrade_building()`；每旬日志显示收支与缺口；银两吃紧时的提醒。
- 界面：顶栏（银两、威望、底蕴）；门派页（收支明细、结余）；**建筑页**、**产业页**。
