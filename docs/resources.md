# 门派资源 v0.1

> 三大资源：**银两、威望、底蕴（暂名）**。本文记录用户给出的设计，以及代码实现状态与待确认项。
> 标注"（我的理解）"的地方是对原话的解读，需要确认；标注"待定"的是用户还没说的部分。

## 1. 总览

| 资源 | 用在哪 | 从哪来 |
|---|---|---|
| **银两** | 购置产业、升级门派建筑 | 产业收获、接任务、**成年弟子供奉**（上缴给门派） |
| **威望** | 外交、招收弟子 | 弟子在江湖的经历（可涨可跌）、任务、帮派踢馆、灭门 |
| **底蕴**（暂名，即"门派经验"） | 解锁技能树 | **待定**（见 §5） |

另有 **历史最高威望**：只增不减，决定**可接任务等级**。

## 2. 银两
- **支出**：购置产业；升级门派建筑。
- **收入**：
  1. 产业收获——每旬从已购置的产业得到收入；
  2. 接任务——完成任务的报酬；
  3. 成年弟子供奉——**成年弟子向门派缴纳**（我的理解：供奉是收入，不是门派发给弟子的俸禄）。
- 成年的年龄线、供奉额度（是否与弟子能力/阶位挂钩）：待定。
- 是否另有"俸禄/日常开支"这类持续支出：待定（目前没有）。

## 3. 威望
- **用途**：外交；招收弟子（质量/数量）。"用来"是**消耗**还是**门槛/加成**：待定。当前实现为加成——威望越高，候选人质量越好（`Recruitment.quality_bonus`）。
- **变动**：靠弟子在江湖的经历累积或减少；任务获得；帮派踢馆、灭门获得。这些来源大多依赖 P1 的江湖与战斗，P0 阶段威望先不会自己变化。
- **历史最高威望 → 任务等级**：取历史最高值，所以威望后来下跌也不会失去已解锁的任务等级。门槛数值为占位（`Balance.TASK_TIER_PRESTIGE` = 0/50/150/400/1000 对应 1~5 级）。
- 门派威望与**弟子个人威望**（弟子状态之一）是两个数；两者是否关联：待定。

## 4. 底蕴（暂名）与技能树
- **用途**：解锁技能树。
- **技能树三大方向**：
  - **发展**——经营方向（产业、建筑、收入效率等）；
  - **策略**——谋略方向（外交、情报、任务等）；
  - **武功**——武学方向（即原来规划的"武学树"，C 类）。
- 各方向的具体节点内容：待定。
- 显示名：暂用"底蕴"，想改只改 `UiText.RES_LEGACY`。备选：道统、积淀、心得、宗学。

## 5. 待确认
1. **底蕴从哪来？**（用户没说）。我的建议：每旬从弟子修炼中汲取——把全体弟子本旬获得的技能经验按比例转化为底蕴，再加上弟子升级、任务奖励。这样"养成越好，门派越有底蕴"，把养成和技能树连起来。
2. **威望"用来招收弟子/外交"是消耗还是门槛？**
3. **成年的年龄线**与**供奉额度**怎么定？
4. **有没有持续支出**（弟子俸禄、建筑维护）？没有的话，银两的压力只来自购置与升级。
5. **荣耀值**（支线任务成绩）保持为"成绩而非资源"，不可花费——是否同意？
6. 第三资源的名称。

## 6. 区分几个容易混的概念
| 概念 | 是什么 |
|---|---|
| 门派威望（资源） | 外交、招收的筹码，可涨可跌 |
| 历史最高威望 | 门派威望的最高纪录，决定任务等级 |
| 弟子个人威望 | 弟子的状态值（雷达图下方） |
| 荣耀值 | 长期成就/成绩，来自支线任务等，不是可花费资源 |
| 弟子技能经验（xp） | 弟子个人的技能进度，与门派底蕴不同 |
